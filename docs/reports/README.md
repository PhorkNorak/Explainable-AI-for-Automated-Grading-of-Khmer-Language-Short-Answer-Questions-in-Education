# Final report and presentation

- [Final report](<Explainable AI for Automated Grading of Khmer Language Short-Answer Questions in Education Report final.pdf>): the author's approved 67-page version with clearer wording, English keywords in the Khmer abstract, all frontier names in both abstracts, the three-model KhmerGrader methods section and the revised prototype wording.
- [Final presentation](Final_Presentation.pdf): a copy of the author's supplied slide PDF. It has not been regenerated from the Markdown decks.

The report is by Phork Norak, supervised by Dr. Khim Chamroeun at the Royal University of Phnom Penh. Its cover date is June 2026. The later editing pass changes wording and presentation, not the reported benchmark values or experimental evidence.

The report was recovered from local writing backups, historical tables and the author-designated report PDF, then revised using the final presentation and the author's review comments. All seven chapters and the appendices received a language pass from printed page 1 to the end. The final PDF preserves the numerical values, tables, formulas, citations, Khmer examples and images, and has 67 pages.

Only this README and the two named PDFs are included from this folder. All editable LaTeX projects remain on disk under `local/manuscripts/` and are excluded from Git. A public checkout can read the PDFs but does not contain the manuscript files needed to rebuild them.

Older original PDFs, the earlier revised version, audit sources, source ZIPs, compiler caches and verification records also remain local. The files here are publication copies; the original working documents have not been moved or deleted.
